## How to use this for mapping

1. **Check descriptions:** For each position number, open `position N.png` and confirm its description in `position-entries-by-number.json` matches the pose (and this group).
2. **Fix mix-ups:** If an entry is in the wrong group (e.g. doggy labeled as missionary), edit the line in the JSON for that `positionNumber`, then run `node scripts/apply-position-mapping.js`.
3. **Bulk naming:** Use the group names (e.g. "Doggy style, male hands on her back") as a starting point; refine with specifics (legs splayed, arched back, etc.) for each position.
